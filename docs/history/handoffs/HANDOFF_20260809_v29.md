## 4. B6 — remediated under G2, re-run LAUNCHED

**A finding first: there was no per-observable bin scoping in the plotting
configuration at all.** `subsample_error_bins_to_exclude` matches on bin name
alone, so it descopes a bin for *every* observable, and the audit target
**deliberately zeroes it** (`run_paper_plots.sh:366`). Neither can express "this
pair, these bins" — so G2 could not be encoded config-only, and a consumer
change was required.

**Implemented:** optional per-pair `multiplicity_scope`; empty means all bins, so
every existing pair is unchanged. Honoured **even under the audit**, because an
undeclared bin is not an observable this analysis claims.

**Exactly two rows carry a scope** — `BplusBcminus.root`, `LbbarBcminus.root` —
set to `["M00_100", "M0_1"]` (integrated + top class; 0–1 % is the
highest-multiplicity class per `Model.tex:126`). **Verified the config diff is
semantically nothing else:** stripping `multiplicity_scope` reproduces the
previous document exactly.

**Message fix.** `"yield technical coverage incomplete"` was used for two
different failures. Now: `"subsample blocks missing"` (a pipeline fault) versus
`"zero in all blocks (coverage complete)"` (an empty observable).
