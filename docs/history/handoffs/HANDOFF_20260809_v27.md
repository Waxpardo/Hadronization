## 2. THE PROBE FIX — landed, and already used

`tools/queue_probe.py`. **Three outcomes, never two:** `QUEUE_EMPTY` (0),
`QUEUE_NONEMPTY` (1), `QUEUE_UNKNOWN` (2, and nonzero so a caller checking only
the exit status cannot read it as empty).

**Emptiness needs two conditions**, which is the whole point: the listing must
exit zero **and** a separate `-totals` probe must return a line naming the
schedd. A command that exits zero while printing nothing because it never
reached the schedd satisfies the first and fails the second — **exactly the case
that produced last session's false QUEUE_EMPTY.**

Six tests, all simulating failures that cannot be exercised against a healthy
cluster. Plus a **live positive control** against the real schedd. **The
campaign's convergence in §1 was verified with it.**
