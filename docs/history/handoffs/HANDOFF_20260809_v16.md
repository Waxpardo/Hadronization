## 3. B4 macro — and the correction is the important part

`a44aad6` added the per-event `TH1D` on the **analysis** counter
(`NCH_PRIMARY_CHARGED_ETA10_V1`: final, charged, non-heavy-flavour,
`pT > 0.15`, `|η| < 1`) — counter index 3, **asserted at runtime** so a ladder
reorder returns 4 rather than filling the wrong axis. Common binning across
arms and tunes; overflow checked and reported, since a clipped tail is exactly
where the top class lives.

**`884f76e` corrects `a44aad6`, which was incomplete in a way that would have
produced convincing wrong output.** The macro hardcoded `Tune:pp = 14` and read
no card, so `tuneLabel` was a label with no effect on physics: **a "per tune"
scan would have produced three identical MONASH samples under three different
labels.** Now:

- **`cardPath` parameter**; card read **first**, macro overrides after, since
  the card carries the tune bundle plus a `pTHatMin` and `Main:numberOfEvents`
  the macro must not inherit. **Unreadable card returns 6**, never falls back to
  Monash silently.
- **The MB arm explicitly turns `HardQCD:hardccbar/hardbbbar` off.** A tune card
  leaves them on, so without this the "MB" sample is a hard sample wearing an MB
  label — **and since the measurement is hard-vs-MB, that inverts the result
  rather than degrading it.**
- Emits `B4_TUNE_CARD=<path> label=<tune>` for the run record.

**NOT SMOKED.** PYTHIA8 is absent on the local machine — `setupEnv.sh` reports
*"CVMFS not available"*, `PYTHIA8: (not set)`, no headers present. ROOT alone
compiles the `TFile`/`TH1D` half but not the generator. **The smoke must happen
on the Nikhef scratch deploy, which is where it runs anyway.**
